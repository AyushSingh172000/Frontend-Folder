# React:-

React is the library(collection of predefined code) of javascript.
We can make single page application with the help of react.

# Feature of React:-
1) Single Page Application.
2) Declarative in nature(user will tell What to do and react know how to do?).
3) Component(Building block of a web page) Based Architecture.(Code with different different block and when merge it will make SPA).
4) Virtual DOM(Exact copy of Real DOM)(React use Diffing Algorithm to compare the difference between real DOM and Virtual DOM and make changes or update in the real DOM with the help of patching).This Process is called Reconcilation.





# Types of Application:-
1) Single Page Application:-(ex:- gmail (Page will not reload))(Cached Storage used) 
It is faster.
Single html page.
Search Engine Optimization is not better.

2) Multi Page Application:- (ex:- Amazon(Page will reload)) 
It is slower.
Multiple html page.
Search Engine Optimization is better.
