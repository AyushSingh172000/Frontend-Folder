# Identifier:- User given name
1. Name of a class
2. Name of a method(Function)
3. Name of a Variable
# Rules of an Identifier:
1.An Identifier can be written by using alphabet(A-Z,a-z),number(0-9) and only two special character(dollar$ and _ underscore).
2.An Identifier must not starts with a number.
3.Any space is not allowed for an Identifier.
4.Any keyword is not allowed for an Identifier.
